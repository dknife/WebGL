# WebGL 3D 그래픽스

『WebGL 3D 그래픽스 — 웹 브라우저에서 배우고 바로 실행하는 3차원 그래픽스』(강영민 지음)의 웹 에디션 저장소입니다.

- **웹 에디션**: https://dknife.github.io/WebGL/
- 각 장의 예제 코드에는 [실행] 버튼이 있어, 예제 바로 아래에서 WebGL 렌더링 결과를 확인하고 코드를 수정해 재실행할 수 있습니다.

## 구성

```
docs/               ← GitHub Pages 루트
  index.html        ← 랜딩 페이지
  book/             ← 책 본문 (chNN.html, front.html)
    book.css        ← 스타일 (손으로 관리)
    book.js         ← 실행·복사 버튼, WebGL 실행기 (손으로 관리)
    viewer.html     ← 그림 확대 보기 (손으로 관리)
chNN/               ← (향후) 장별 예제 코드
```

`docs/book/chNN.html`은 LaTeX 원고에서 자동 생성됩니다. 직접 수정하지 마세요.
