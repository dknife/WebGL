PREFACE

머릿말

이 책 『WebGL 3D 그래픽스』는 3차원 컴퓨터 그래픽스를 웹 브라우저에서 직접 실행해 보며 배우고자 하는 독자를 위해 준비하였습니다. 3차원 그래픽스는 게임, 영화, 가상현실, 디지털 트윈, 데이터 시각화에 이르기까지 현대 소프트웨어의 핵심 기술로 자리 잡았지만, 이를 배우려면 복잡한 개발 환경을 설치하고 낯선 수학과 씨름해야 한다는 부담이 앞서곤 합니다. WebGL은 이 부담을 크게 덜어 줍니다. 웹 브라우저만 있으면 어떤 운영체제에서든 그래픽스 프로그램을 작성하고 즉시 실행해 볼 수 있기 때문입니다.

『WebGL 3D 그래픽스』는 3차원 그래픽스의 핵심 이론과 WebGL 프로그래밍 기법을 12개 장으로 정리하였습니다. 렌더링 파이프라인과 셰이더, 기하 변환과 카메라, 조명과 텍스처에 이르는 그래픽스의 근간을 다지고, 마지막 IV부에서는 애니메이션과 상호작용, 고급 렌더링 기법, 그리고 Three.js를 이용한 실전 프로젝트까지 나아갑니다. 필요한 수학은 해당 개념이 처음 쓰이는 곳에서 그때그때 설명하여, 선형대수를 미리 공부하지 않은 독자도 따라올 수 있도록 하였습니다.

이 책의 모든 예제는 웹에서 바로 실행해 볼 수 있습니다. 이 책의 웹 에디션(https://dknife.github.io/WebGL/)에서는 각 예제 코드 바로 아래에서 실행 결과가 렌더링되는 모습을 직접 확인하고, 코드를 고쳐 가며 실험할 수 있습니다. 그래픽스는 눈으로 결과를 확인할 때 가장 빠르게 배울 수 있는 분야입니다. 예제를 실행해 보고, 값을 바꾸어 보고, 화면이 어떻게 달라지는지 관찰하는 과정을 반복하시기 바랍니다.

끝으로, 이 책이 나오기까지 도움을 주신 모든 분께 깊이 감사드립니다.

저자 일동

이 책의 구성

전체 구성

이 책은 4개의 파트, 12개의 장으로 이루어져 있습니다.

  • I부 WebGL 시작 (1–3장) 3차원 그래픽스의 기본 개념과 렌더링 파이프라인, 첫 WebGL 프로그램, 셰이더와 GLSL을 배웁니다.
  • II부 기하 변환과 카메라 (4–6장) 그래픽스를 위한 벡터·행렬, 이동·회전·크기 변환, 카메라와 투영을 학습합니다.
  • III부 실감 렌더링 (7–9장) 조명과 셰이딩, 텍스처 매핑, 3차원 메시와 모델을 다룹니다.
  • IV부 한 걸음 더 (10–12장) 애니메이션과 상호작용, 고급 렌더링 기법, Three.js 실전 프로젝트를 다룹니다.

각 장의 구성

모든 장은 다음과 같은 일관된 흐름으로 구성되어 있습니다.

  • 챕터 도입부 장식 숫자와 그림, 그리고 해당 장을 학습한 뒤 할 수 있게 될 목표를 정리한 이 장을 마치면 박스로 구성됩니다.
  • 본문 개념 설명, 코드 예제, 실행 결과를 통해 3차원 그래픽스 이론과 WebGL 프로그래밍을 단계적으로 학습합니다.
  • 이 장의 실습 장의 마지막에 실습 문제를 모아 제시하며, 해답 코드를 함께 수록하여 자가 학습이 가능하도록 하였습니다.
  • 요약 해당 장에서 배운 핵심 내용을 항목별로 정리하여 복습에 활용할 수 있습니다.
  • 연습문제 배운 내용을 스스로 점검할 수 있는 다양한 유형의 문제를 제공합니다.

웹 에디션과 예제 실행

이 책의 웹 에디션은 https://dknife.github.io/WebGL/ 에서 서비스됩니다. 웹 에디션의 각 코드 예제에는 [실행] 버튼이 붙어 있어, 예제 바로 아래에 WebGL 캔버스가 열리고 실행 결과가 렌더링됩니다. 코드를 수정하여 다시 실행할 수도 있으므로, 값을 바꾸어 가며 개념을 실험적으로 확인해 보시기 바랍니다.
