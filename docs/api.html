WebGL API 레퍼런스

WebGL 1.0과 2.0의 전체 메서드를 담았습니다. 함수 이름·설명·파라미터로 검색하면 시그니처와 각 파라미터의 뜻을 한국어로 보여줍니다. 난이도를 배경색으로 구분합니다 — 초급(초록)은 첫 삼각형·기본 렌더링, 중급(파랑)은 프레임버퍼·상태 제어 등, 고급(주황)은 WebGL 2.0 전용·특수 기능입니다. 예: vertexAttribPointer를 검색해 보세요.
